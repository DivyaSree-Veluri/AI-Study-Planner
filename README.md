# AI Study Planner 📚

## Overview
AI Study Planner is a Python-based project that helps students create a personalized study schedule based on:
- Subjects to study
- Days left until exams
- Available study hours per day

The project automatically distributes study time across subjects and generates a day-wise study plan.

## Features
✅ Accepts multiple subjects as input

✅ Takes exam countdown and daily study hours

✅ Generates a day-wise study schedule

✅ Easy to use and beginner-friendly

✅ Can be enhanced with AI-generated personalized plans

## How It Works

1. User enters subjects.
2. User enters number of days left for exams.
3. User enters available study hours per day.
4. The program calculates study time allocation.
5. A study plan is generated for each day.

## Example

### Input

Subjects: DSA, Java, DBMS

Days Left: 15

Hours Per Day: 4

### Output

Day 1

DSA - 1.3 hours

Java - 1.3 hours

DBMS - 1.3 hours

Day 2

DSA - 1.3 hours

Java - 1.3 hours

DBMS - 1.3 hours
